# Exercícios de C — Fundamentos da Programação de Computadores

Repositório destinado ao registro das minhas resoluções dos exercícios do livro **Fundamentos da Programação de Computadores**, de **Ana Fernanda Gomes Ascencio** e **Edilene Aparecida Veneruchi de Campos**.

O objetivo deste repositório é acompanhar minha evolução no aprendizado da linguagem C e, principalmente, desenvolver minha capacidade de **raciocínio lógico e resolução de problemas por meio da programação**.

Capítulos completos: 3 e 4.
Capítulo atual: 5 (não finalizado)
